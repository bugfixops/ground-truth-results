## Scope notes

- The shutdown action is an ordinary branch: it calls `finish()` and returns from `onCreate`; it is not an ENV or STATE gate. The later `onStart` edge is conditional on both this return not occurring and AOSP not seeing `mFinished`.
- The `MainFragment` XML declaration is evidence that the chosen layout requests this fragment. The actual instantiation/callback route passes through AndroidX and is therefore marked `non_standard` / INFERRED pending library-source evidence.
- `subscribeMsgViewModel` and `subscribeSessionStats` register Rx observers. They are useful route candidates but do not alone prove the event source or event delivery. Keep any path depending on them OPEN until those links and guards are separately established.
- `onPostCreate`, options-menu callbacks, permission callbacks, drawer listeners, and search callbacks appear in the printed source, but their dispatch originates in framework/AppCompat/permission-library code outside this bounded edge table. Do not infer callback edges from method presence. Add them only with separately verified dispatch evidence (AOSP for framework claims; INFERRED for absent library source).
- No `needs_state` or `env` gates are established for the listed cold-start/lifecycle edges. Do not convert ordinary `if` conditions into structured gates.
