What was reviewed by hand (class level, from method names, the manifest, layouts and the fixtures on the baseline device):

- **Environment gates (edges into these classes carry `env`):** `DocumentShareIntoFragment` and its import-options fragment (another app shares text or a file to Markor); `StoragePermissionActivity` and `GsPermissionChecker` (the baseline emulators had runtime permissions pre-granted, so the permission screen never shows); the launcher widgets and the shortcut entry (`TodoWidget*`, `WrFilesWidget*`, `WrMarkorWidgetProvider`, `WrWidgetConfigure`, `OpenFromShortcutOrWidgetActivity`: the user must add them on the home screen). The exported entries of `DocumentActivity` (VIEW / EDIT / SEND intents from other apps) keep their `env` edge from `S_ENTRY`; the in-app route (file browser -> `DocumentActivity`) is preferred when it exists.
- **Content gates (`needs_state`):** password-based file encryption (`JavaPasswordbasedCryption`, `PasswordStore`: an encrypted `.jenc` note, or encryption chosen in the New file dialog); `.csv` documents (`CsvTextConverter`, `CsvSyntaxHighlighter`, `CsvConfig`: `table.csv` exists in the Download fixtures, so opening it is a path step); Wikitext documents (`Wikitext*`); todo.txt documents (`TodoTxt*`); KaTeX math in Markdown (`FlexmarkKatexExtension`). The Download fixtures hold 19 files (`archive.zip`, `config.xml`, `contacts.vcf`, `data.json`, `events.ics`, six images, `journal.md`, `notes.md`, `page.html`, `sample.pdf`, `table.csv`, `tasks.org`, `todo.txt`, `sample_deck.apkg`), so csv, todo.txt and org files were on the device, but in `Download`: the `Documents` fixture folder, Markor's default notebook location, is missing (an open question for Yang), and whether the tools opened the Download files is not known. There is no `.jenc`, Wikitext, AsciiDoc or KaTeX sample, so those gates stay.
- **Branch gates read from the source at the frontier (`CFG['EDGES']`):** `DocumentActivity.handleLaunchingIntent` -> `showShareInto` for `ACTION_PROCESS_TEXT` (another app sends selected text: `env`); AsciiDoc documents (`Asciidoc*`, `WrAsciidoc*`) join the content gates.
- **Dead code** is mostly unused code of the bundled `gsantner.opoc` utility library: `GsSharedPreferencesPropertyBackend` (55 of 101 methods), `GsContextUtils` (48 of 167), `GsMapPropertyBackend`, `GsFileUtils`, `GsNetworkUtils` (all 16: downloads are never used), `GsNanoProfiler`, `GsCollectionUtils`, `GsTextUtils`, plus about 17 unused getters of `AppSettings`.
- **Not gated but never run:** the text-editing toolbar (`ActionButtonBase`, `MarkdownActionButtons`, `TodoTxtActionButtons`, `WikitextActionButtons` and the dialogs of `MarkorDialogFactory`) and `GsMenuItemDummy` (a no-op `MenuItem` implementation, 42 methods). They are reachable by taps inside an open document; the baseline opened documents (`DocumentEditAndViewFragment` ran) but did not exercise these.
- **Receiver variants.** `Gs*Base` classes are template bases (`GsActivityBase`, `GsFragmentBase`, `GsPreferenceFragmentBase`): methods such as `MarkorBaseActivity.onCreate@DocumentActivity` are the same method running for one concrete subclass.
