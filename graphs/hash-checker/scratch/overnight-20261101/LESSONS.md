# hash-checker — lessons from the Stream D re-verification (2026-11-01, local mirror)

- The built flavor matters more than the file name: `MainActivity.java` exists only under `src/thirdPartyStores/`, not `src/main/`. A source index that prefers `src/main/` or the shortest path silently picks the wrong flavor (here it would have picked googlePlay); the mirror must hold only the built flavor's copy.
- A redrawn stratified sample can be identical to the previous final sample: when the graph is unchanged, `verify_sample.py` with the same seed returns the same 30 methods. The error rate for the redraw (0/30 here) must not be confused with the historical rate (13/37, 0.351) from before the fixes landed in `graph_def.py`.
- Bytecode line citations need range-aware checking: hand-written edges cite ranges (e.g. `HashCalculatorFragment.java:166-189` for a switch), and javac attributes a `new` inside a multi-line expression to the expression's first line (e.g. `App$1` at `App.java:58` for an anonymous class written at :59). A single-line token check flags these falsely.
- `check_bytecode_lines.py` "file not found" failures mean the local mirror is incomplete, not that the graph is wrong: all 73 first-run failures were files outside the sample mirror, and all cleared once the 15 cited files were fetched (548 checked, 0 bad).
- The connector has a display-size ceiling: `ActivityManagerService.java` (1,086,106 bytes) cannot be fetched through it, so its two cited line ranges stay unverified from this VM even though every other framework citation verifies. A size-blocked citation is a tooling limit, not evidence against the label.
- Legacy `DEAD`/`FRAMEWORK_ONLY` dicts in `graph_def.py` are not leftover failures: the build converts them to `UNREACHABLE` and clears them, and the built JSON contains neither key. Grep counts on `graph_def.py` alone mislead; the JSON is the check.
- `scan_unreachable.py --callers` flags exactly the cases the graph already explains: virtual dispatch that never reaches a base implementation, and SUPPRESSed closed-by-configuration edges. Four flags, all explained, is the expected clean result here.
