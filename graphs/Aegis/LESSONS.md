# Aegis — lessons from the re-audit

- Read every route step against printed source, including branch conditions: the toolbar lock-icon step and the intro Next-step jump were both branch crossings that looked like valid routes until the guard text was printed, and both needed graph fixes, not verdict changes.
- When one shared node serves two caller chains, split it, and give shared dialog and callback nodes per-caller edges: producer-chain-only variant nodes (the doShortcutActions@SCAN technique, reused for the selectIcon split and for the per-importer @FILE variant chains) fixed structural ERROR steps without touching tools and without deleting routes; likewise the Dialogs OK-button node and the showTextInputDialog$7 listener fan out to different importer decrypt paths, and a single shared edge misroutes all of them.
- Re-print before defending an edge: the Stratum decrypt edge survived review until a fresh print of the file-path fallback proved it false, and it was then removed with zero label flips. A correction that changes no label is still a real fix, and it must be recorded as one.
- For generated code, grep first and label the gap: a zero-hit app-tree grep is what justifies the Glide UNREACHABLE cluster, and INFERRED with "source not read" is what keeps Hilt, protobuf-runtime and Glide framework edges honest instead of overstated.
- A first plausible closure can be wrong and the tool run is what catches it: closing the export filter path as closed_by_configuration was reversed when a tool run showed the filter chain running, so the four filter methods stayed REACHABLE with the trigger recorded as an open device item.
- A route's cheapest prefix is not its genuine prefix [UPDATED VERDICT — confirmed against audited new table row 5]: the RawSlot route was first judged WRONG because the router's NONE-intro prefix contradicted the @RAW chain's password-vault requirements; on the V3-corrected redraw it is judged UNCLEAR on a new 42-step @IMP route (producer-less type-0 slot premise, every step true on action and operative condition, no step false). A verdict must follow the printed guards, not the shortest path.
- Fix rounds need a fresh redraw, not a verdict edit: the final table covers only the post-fix redraw (25 routes, 1093 steps, 446 distinct edges, seed 20261025), judged fresh, with no prior verdict carried over except the 23 edge-identical carried rows whose verdicts and decisive summaries are carried unchanged; dropped rows' verdicts are superseded, not carried over. Distinct-count rate rule: fixed routes are counted once, so the distinct rate is 3/14 = 0.2143, not the table-formula 3/16 = 0.1875; a route not in the first-draw sample cannot become fixed.
