# ground-truth-results

Schema 2 ground-truth trigger graphs for the 13 Android apps (ICST 2027).

- graphs/<app>/out/: trigger graph (JSON, HTML), methods.csv, build report
- graphs/<app>/graph_def.py, AGENT_NOTES.md, verification.csv, readme_notes.md, LESSONS.md
- handoff/: progress and run summaries
- tools/: build scripts
